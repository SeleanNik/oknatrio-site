# Сайт «Трио» (oknatrio.ru)

Статический сайт на Astro. Контент — в Markdown, формы — через PHP.

## Запуск

```bash
npm install
cp .env.example .env     # на Windows: copy .env.example .env
npm run dev              # http://localhost:4321
npm run build            # сборка в dist/
```

`/ui-kit/` — внутренняя страница с компонентами (закрыта от индексации, не попадает в sitemap).

## Настройки

| Что | Где |
| --- | --- |
| Домен, noindex, ID Метрики | `.env` (`PUBLIC_SITE_URL`, `PUBLIC_NOINDEX`, `PUBLIC_YM_ID`) |
| Телефон, e-mail, адрес, график, мессенджеры | **админка `/admin/`** (хранится в `public/data/site.json`) |
| Реквизиты, юр. название | `src/config/site.config.mjs` |
| Меню | `src/config/nav.mjs` |
| Калькулятор (цены, коэффициенты) | `src/config/pricing.mjs` |
| Технические каталоги | `src/config/site.config.mjs` → `catalogs` |
| Отзывы | **админка `/admin/`** (`public/data/reviews.json`) |
| Работы | `src/config/works.mjs` (в админку — следующий этап) |
| Фото (пока Unsplash) | `src/config/img.mjs` |
| E-mail для заявок | админка `/admin/` → «Заявки» (или `form-config.php` на сервере) |

## Как добавить страницу

- **Вид (двери, фасады…) в разделе**: добавить объект в `types` нужного раздела в `src/config/razdely.mjs` — карточка, якорь, меню и футер обновятся сами.
- **Информационная страница**: файл в `src/content/pages/` (id = URL).
- **Новый раздел**: объект в `razdely.mjs` + пункт в `src/config/nav.mjs`.

## Деплой

1. В `.env` на сборке: `PUBLIC_NOINDEX=false`, реальные `PUBLIC_SITE_URL` и `PUBLIC_YM_ID`.
2. `npm run build`, загрузить содержимое `dist/` на PHP-хостинг.
3. На сервере создать `form-config.php` из `form-config.example.php` (e-mail получателя, отправитель на домене сайта).
4. В `.htaccess` раскомментировать редирект окнатрио.рф → oknatrio.ru; старые URL перенести из файла `redirects`.
5. Проверить отправку каждой формы (callback, measure, calc) и получение письма.

Список данных, которые нужно получить от клиента: `CONTENT_TODO.md`. Ключевые решения: `CLAUDE.md`.

## Админка (`/admin/`)

PHP-админка с базой данных (по умолчанию SQLite, ничего настраивать не нужно). Контент публикуется в `/data/*.json`, сайт подтягивает его при открытии страницы, пересобирать не нужно.

**Первый запуск:** после загрузки на хостинг сразу откройте `https://домен/admin/` и создайте аккаунт владельца (имя, e-mail, пароль от 10 символов). Пока владельца нет, это может сделать любой, не откладывайте.

**Что редактируется (по страницам):**
| Страница | Что можно менять |
| --- | --- |
| Главная | заголовок главного экрана, блоки «Продукция» (5 карточек: название, бренд, фото, ссылка), «Услуги», «Наши работы» |
| Алюминиевые окна | заголовок, подзаголовок, виды Alutech и Schuco (фото, текст, особенности; можно добавлять и удалять), характеристики, вопросы и ответы |
| Окна ПВХ | то же для VEKA |
| Наши работы | подзаголовок, список объектов (фото, название, место, метки; порядок, добавление, удаление) |
| Тех. информация | подзаголовок, PDF-каталоги Alutech / Schuco / VEKA (загрузка, названия, порядок), карточки профилей VEKA |
| Контакты | телефон, e-mail, адрес, график, WhatsApp, Telegram |

Списки (работы, виды, каталоги, вопросы) показаны компактными карточками, как на сайте: нажмите на карточку, чтобы изменить её в окне, кнопка «Создать» добавляет новую, стрелки меняют порядок. Работам и видам можно добавить **несколько фото**: на сайте они плавно листаются (автоматически, по точкам и свайпом), первое фото служит обложкой. До 8 фото в карточке.

У каждой страницы есть история: 20 последних версий и откат. Фото: jpg/png/webp до 4 МБ. PDF: до 100 МБ (но не больше лимита хостинга `upload_max_filesize`/`post_max_size`).

**Сотрудники и права:** аккаунты создаёт, меняет и удаляет только владелец (e-mail, имя, пароль, роль). Каждому сотруднику владелец выдаёт права отдельно: аналитика, любая из страниц. Права действуют сразу, отключённый или удалённый сотрудник теряет доступ немедленно. Пароль сотрудник сам не меняет и сбросить его без владельца не может.

**Аналитика** (раздел «Обзор»): визиты, просмотры, отправленные заявки (по успешной отправке формы), конверсия, график по дням, популярные страницы, источники и устройства. Собственный счётчик: без cookie и без персональных данных (посетитель обезличен и меняется каждый день), боты не считаются, учитывается «Не отслеживать». Яндекс.Метрика при желании работает параллельно (`PUBLIC_YM_ID`).

**Безопасность:** пароли bcrypt, вход в два шага (TOTP, включается в «Мой профиль»), блокировка перебора (5 неудач за 15 минут), CSRF на всех действиях, сессия 8 часов, журнал действий. Загрузки проверяются по содержимому, `uploads/` не исполняет скрипты, `admin/inc/` и `admin/_data/` закрыты `.htaccess`.

**Хостинг:** PHP 7.4+ (лучше 8.x), расширения `pdo_sqlite` (или `pdo_mysql`), `mbstring`, `fileinfo`. Права на запись для `data/`, `uploads/`, `docs/files/`, `admin/_data/`.

**MySQL вместо SQLite** (по желанию, до начала работы): создайте базу в панели хостинга и файл `admin/_data/db.json`:
```json
{ "driver": "mysql", "host": "localhost", "name": "имя_базы", "user": "пользователь", "pass": "пароль" }
```

**Важно при обновлении сайта через FTP:** не перезаписывайте и не удаляйте на сервере `data/`, `uploads/`, `docs/files/`, `admin/_data/` (там база, пароли, загруженные файлы и контент). Папку `admin/_data/` стоит периодически копировать. Перед пересборкой скачайте актуальные `data/site.json`, `data/pages.json` в `public/data/` проекта, чтобы SEO-снимок в HTML был свежим. Меню сайта (выпадающие списки видов) обновляется при пересборке, остальные правки видны сразу.

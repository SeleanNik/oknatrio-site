# CLAUDE.md — сайт «Трио» (oknatrio.ru)

Спілкування з власником — українською. Мова сайту — російська. Відповіді стислі, одна чітка рекомендація.

## Ключові рішення
- Компанія: віконна «Трио», Москва, Солнцевский пр-кт, д. 15. Алюмінієві вікна, ПВХ, балкони, комплектуючі, монтаж.
- Домен: основний oknatrio.ru; окнатрио.рф → 301 на основний. Базовий URL — лише в одній змінній конфігу (`site.config`), у коді не зашивати.
- Стек: Astro (static) + контент у Markdown/колекціях, чистий CSS з токенами у CSS-змінних, шрифти локально (без Google Fonts).
- Форми: PHP-обробник → e-mail (адреса в конфігу), honeypot, чекбокс згоди 152-ФЗ. Аналітика: заглушка Яндекс.Метрики (ID в конфігу).
- Модалки (не сторінки): Заказать звонок · Вызвать замерщика · Заявка на расчёт.
- URL латиницею, читабельні (`/okna/pvh/`, `/balkony/teploe-osteklenie/`).
- SEO: унікальні title/description, хлібні крихти, sitemap, robots, noindex на dev, schema.org LocalBusiness (головна + контакти), WebP/AVIF + lazy-load, a11y.
- Файл `redirects` — заготовка для 301 зі старих URL (заповнює власник).
- Фото тимчасово з безкоштовних стоків (Unsplash тощо), потім заміна. Тексти — чорнові; усе, що треба від клієнта, маркувати `TODO:` і вести в `CONTENT_TODO.md`.
- Mobile-first, помітні CTA, багато фото об'єктів.

## Дизайн (затверджено)
- Палітра: navy `#12324a`, blue `#2a74a6`, CTA amber `#f5b83d`, тло `#f6f7f8`. Усе в `src/styles/tokens.css`.
- Шрифти: Manrope (заголовки) + Inter (текст), локально через `@fontsource-variable/*`.
- Радіуси 16–22px, кнопки-пігулки, скло лише в hero. Мобільна фіксована панель «Позвонить / Вызвать замерщика».
- Лого — тимчасовий текстовий wordmark (`Logo.astro`). Хостинг: PHP є.

## Структура коду
`src/config/` site.config.mjs (URL, телефон, Метрика), nav.mjs (меню), schema.mjs · `src/components/` · `src/layouts/Base.astro` · `src/scripts/ui.js` (меню, модалки, форми) · `public/form-handler.php` + `form-config.php` (створити на сервері з example).
Запуск: `npm install && npm run dev` (http://localhost:4321), `/ui-kit/` — перевірка компонентів. `.env` → `PUBLIC_SITE_URL`, `PUBLIC_NOINDEX`, `PUBLIC_YM_ID`.

## Структура сайту (мінімум за вимогою клієнта)
`/` · `/okna/alyuminievye/` · `/okna/pvh/` · `/tehnicheskaya-informaciya/` · `/kontakty/` · `/politika-konfidencialnosti/` (лише посилання у футері/формах) · 404 · `/ui-kit/` (службова). **Цін на сайті немає** (клієнт: ціни часто змінюються) — калькулятор і сторінку «Цены» прибрано, ціни з усіх блоків вилучено. Балкони й комплектуючі — «види» всередині розділів (балкони: холодне в алюмінії, тепле в ПВХ). Меню: Продукция (випадне: алюміній/ПВХ + види) · Наши работы (якір `/#raboty`) · Техническая информация (окрема сторінка `/tehnicheskaya-informaciya/`) · Контакты (+ телефон, кнопка замірника). Пункт «Услуги» з меню прибрано (блок «Услуги» лишився на головній). Шапка біла, 60px, 15px semibold.
- Сторінки-розділи — дані в `src/config/razdely.mjs` (SEO, hero, «види» з якорями, характеристики, FAQ, SEO-текст), макет `layouts/RazdelLayout.astro`. Нові види = новий об'єкт у `types`; меню й футер будуються з нього автоматично.
- Інфо-сторінки — Markdown у `src/content/pages/` (id = URL). Один маршрут `pages/[...page].astro` обслуговує обидва джерела.
- Меню (`config/nav.mjs`): випадні меню в стилі Apple (на всю ширину, матове скло, затемнення, плавна поява) з видами кожного розділу. Шапка компактна (60px), CTA в один рядок.

- Логотип клієнта: `public/img/logo.png` (38×40, помаранчево-жовті квадрати) + текст «ТРИО»; потрібен SVG/більший файл.

Низ hero плавно переходить у фон секції «Продукция» (#0b1522 → #12161c → «Услуги»). «Продукция» — bento-сітка з великих фото-карток зі скляним підписом; далі «Услуги» (темна секція: рядок брендів + 4 картки з «вирізом»), «Наши объекты», «Техническая информация» (темна секція, два сухі каталоги Алюміній / Пластик ПВХ), відгуки, заявка, контакти.
- Зайві сторінки першої версії (14 сторінок окон, бренди, статті, монтаж, гарантії, відгуки) перенесені в `_archive/` (не збирається, не в git); також калькулятор, «Цены», «Наши работы», «О компании», Балконы, Комплектующие.

## Админка (PHP + БД) — этап 3 (по страницам, права, аналитика)
- Дизайн по референсу клиента: светлая рамка, тёмная боковая панель с иконками и группами («Страницы сайта», «Администратор»), пастельные карточки-показатели, серые панели. Разделы «Отзывы», «Заявки», «Настройки» убраны (заявки идут только на e-mail через `form-handler.php` + `form-config.php`; отзывы на сайте читают `public/data/reviews.json`, в админке не редактируются).
- Структура: `public/admin/index.php` (контроллер) + `inc/` (lib — ядро/сессия/TOTP/загрузки, db — PDO SQLite|MySQL, права `PERMS`, контент с версиями, журнал; schema — описание полей страниц и универсальные форма/проверка; stats — аналитика и SVG-график; ui, pages). `inc/` закрыта `.htaccess`.
- Контент страниц: БД (`content`, ключи `page_<имя>` и `site`) → публикация в `public/data/pages.json` и `site.json`. Сборка Astro читает те же файлы (`src/config/pages.mjs`, `razdely.mjs`, `tech.mjs`, `works.mjs`, компоненты главной), а `src/scripts/live-data.js` в браузере подтягивает актуальное и клонирует готовые карточки (так сохраняются стили). Новое редактируемое поле: добавить в `page_schemas()` (schema.php) + `data-ed*` в разметке + обработку в live-data.js.
- Права: роль `owner` (всё) или `staff` с отдельными правами (`analytics.view`, `page.*`), владелец выдаёт их на странице сотрудника. Аккаунты создаёт/меняет/удаляет только владелец; сотрудник пароль не меняет; «Забыли пароль» нет.
- Аналитика: `public/stat.php` (приём) + `src/scripts/stat.js` (отправка; пропускает порт 4321 и DNT); таблица `hits`; посетитель = обезличенный хеш за день (без cookie).
- Тест локально: портативный PHP (`php -S`) на копии `dist/`; сценарий `scratchpad/admintest2.mjs` (страницы, загрузки, права, сотрудники, аналитика).
- Списки в админке: компактные плитки + окно `<dialog>` с полями (поля остаются в форме, поэтому сохраняются обычным POST); поле `gallery` (до 8 фото, `images[]`) у работ и видов. На сайте карточки с несколькими фото получают `data-gallery` и оживают в `src/scripts/slider.js` (кроссфейд, точки, свайп, пауза при наведении, только видимые). Первое фото = обложка и держит размер карточки в потоке.
- Права и аккаунты: `PERM_INFO` (ui.php) описывает переключатели и подсказки; роли выбираются карточками; обзор — сетка на 12 колонок без пустот.
